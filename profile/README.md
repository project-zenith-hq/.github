## 🎯 CURRENT MISSION

**SIH26092 — AI-Driven Scheme Matching for Marginalized Entrepreneurs**

Government financial schemes exist — finding the *right* one doesn't. Entrepreneurs can't easily tell what they qualify for, what it's worth, or how to apply. **ASTRA-X is building the AI layer that closes that gap** — from profile to eligibility to a completed application.

<div align="center">

```
   USER PROFILE → ELIGIBILITY → SCHEME MATCHING → RANKING
        → FINANCIAL ANALYSIS → DOCUMENTS → PARTNER DISCOVERY → APPLY
```

</div>
